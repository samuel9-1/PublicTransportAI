# PublicTransportAI 🚌

### Public Transport Demand Forecasting Using Machine Learning

PublicTransportAI is a machine learning-based application for public transport analytics and fare prediction. It analyzes travel data such as source, destination, distance, bus type, and journey duration to estimate fares and support data-driven transportation planning.

## 🚀 Features
- Public transport dataset analysis
- Travel fare prediction
- Data preprocessing and visualization
- Machine learning model integration

## 🛠️ Technologies Used
- Python
- Pandas and NumPy
- Scikit-learn
- Machine Learning

## 📂 Project Structure
- `app.py` — Application code
- `Public_Transport_Demand_Dataset_150k.csv` — Transportation dataset
- `requirements.txt` — Python dependencies

## ⚙️ Installation

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
cd PublicTransportAI
python -m pip install -r requirements.txt
```

## ▶️ Run the Application

Run the command appropriate for your application framework.

## 📌 Project Purpose
To demonstrate how machine learning can support fare estimation, transportation data analysis, and smarter public transport planning.
